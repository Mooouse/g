# game_platform

**Платформа для быстрой и качественной разработки простых игр AI-агентами.** Это комплексный продукт — не движок и не генератор. В нём:
- **инструкции** для агента;
- **правила** площадок и аудиторий как код;
- **готовые конструкции**, проверенные на реальной игре;
- **инструменты** с понятными ошибками;
- **автоматический QA**, упаковка и документация.

## Цель

Агент по короткому брифу («игра для малышей: фрукты и счёт») выпускает простую игру, готовую к публикации:
- **быстро:** минуты или часы, а не дни;
- **с предсказуемым качеством:** проверки зелёные, правила Google Play, Families и COPPA соблюдены;
- **без переписывания** типового кода.

Платформа **общая**: одно ядро и одни правила для разных возрастов (2–5, 6–8, 9–12, 13+) и каналов (Google Play, CrazyGames, веб). Жанр задают наборы конструкций: `kids` — для детей, `casual` — для подростков и взрослых. Жанр, которого нет в наборах (survivors-like, головоломка с уровнями, физика), пишется своим кодом в `kit: code`, но на правилах, портале, рекламе, сохранениях, QA и упаковке платформы. Новый жанр — это новый набор или игра на `kit: code`, а не новая платформа.

**Метрика успеха:** время от брифа до «`validate` без ошибок + `qa` зелёный + `build`» у агента без контекста. Эталон — Balloon Pop: ≈4 ч в одной AI-сессии без платформы.

## Как это работает

[fence]
бриф → games/<id>/game.yaml → gp validate (правила, ошибки с подсказкой) → gp dev → gp qa (проверки в браузере) → gp build
[fence]

Игра — это один файл `game.yaml` (для `kit: code` — ещё её модуль `main.ts`). Платформа собирает её из каталога конструкций и проверяет по профилям аудитории (`ages-2-5`, `ages-6-8`, `ages-9-12`, `general`) и канала (`android-families`, `android`, `web`, `crazygames`).

## Быстрый старт

[fence]sh
npm install
npm run gp -- validate balloon-pop     # проверить пример детского кита (docs/examples/kids)
npm run gp -- dev balloon-pop          # играть в браузере (тестовая реклама)
npm run gp -- qa balloon-pop           # полный QA, отчёт в docs/examples/kids/qa/report.md
npm run gp -- new my-game --from balloon-pop --title "My Game"          # детская игра на ките внутри платформы (games/my-game)
npm run gp -- init ../my-game --id my-game --title "My Game"            # игра своим кодом (13+) в своём репозитории
npm run check                          # типы, тесты, все игры валидны, справочник актуален
[fence]

Нужен Node 22.18+. `npm run gp -- doctor` проверяет окружение.
