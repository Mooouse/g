# Melody Forge

A responsive HTML5 musical merge puzzle with CrazyGames SDK v3 integration, English/Russian/Spanish, procedural levels, Web Audio music, upgrades, auto-save and a first-launch tutorial.

## Playing

Merge two instruments of the same tier by tapping them in sequence. Choose an instrument and press Play a Note to send a soundwave into nearby sealed tiles. Unlock every tile to complete the level. More advanced instruments have greater range and power. Spend earned Gold Notes on upgrades, and summon fresh instruments on empty unlocked squares. Energy recharges over time.

## Deployment

GitHub Pages uses repository root (main branch). SDK runs in a graceful development fallback outside CrazyGames. No dependencies or build step.
