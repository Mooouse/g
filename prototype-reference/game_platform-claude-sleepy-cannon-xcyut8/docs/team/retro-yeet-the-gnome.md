## Разговор ролей

**QA:** Главное в отчёте — баг ядра, который не поймали ни `gp qa`, ни тесты игры, а нашёл ревьюер-агент. Двойной клик по
кнопке рекламы запускал две: `lastAdSec` ставился только после показа, а пауза хоста считала причины, а не вызовы, и конец
второй рекламы снимал паузу посреди первой. Любая игра на `kit: code` могла на это наступить.

**Разработчик:** Исправлено в `AdManager`: пока реклама грузится или на экране, вторая заявка сразу получает отказ
(`rewarded` → `false`, `adBreak` ничего не делает). Есть `host.adPending`. Юнит-тесты на оба случая.

**Маркетолог:** CrazyGames требует слушаться настройки `muteAudio` портала. Агент читал SDK в обход платформы. Теперь
портал отдаёт `muted()` и `onMuteChange()`, хост глушит `host.audio` своим узлом громкости, App — звук и голос в китах.
В поддельный SDK production-проверки добавлены `settings` и слушатель.

**Геймдизайнер:** Мета-прогрессия — 60 одинаковых строк в каждой игре. `UpgradeShop` в ядре: цены по геометрии, «нужно
сначала», «можно купить», покупка без побочных эффектов, форма сохранения и бот «сначала самое дешёвое». Рецепт бота баланса —
в `code-games.md`: пороги целей ставятся *по* кривой бота, а не наугад.

**Аналитик:** Обложки решают CTR на Basic Launch (цель 2–4%). `gp covers` снимает размеры канала из профиля и превью 200×112,
по договорённости `?cover` → `body[data-cover=ready]`, которую придумал агент. Трейлер пока рецептом (виртуальные часы).

**PM:** Игра жила в своём репозитории, `@gp/core` не находился без ссылки на `node_modules`. Теперь Vite получает
псевдонимы `@gp/*` из `exports` пакетов, и dev-сервер разрешает папку игры. Проверено: Yeet собирается без ссылки.

## Не сделано (очередь)

- `gp trailer` — видео из игры на виртуальных часах (рецепт в `tools/video.mjs` у game4).
- `host.qa({ cover })` вместо договорённости по URL — если появится вторая игра, которой так удобнее.

## Для агента Yeet the Gnome (его репозиторий не правил)

- Можно убрать обход `muteAudio` из `main.ts` — платформа делает это сама (`host.portalMuted` для своих звуков).
- `busy` вокруг рекламы можно оставить (он глушит и другие кнопки), но двойная реклама теперь невозможна и без него.
- `data.ts`/`bot.ts` можно перевести на `UpgradeShop` — цены совпадают до монеты (тест `upgrades.test.ts`).
