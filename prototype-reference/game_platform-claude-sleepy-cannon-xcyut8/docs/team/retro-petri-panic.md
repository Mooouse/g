# Разбор: Petri Panic — первая игра, сделанная без платформы

> **2026-09-30: CrazyGames отклонил игру** — «The concept is quite close to existing titles». Сборка была ни при чём; разбор и что изменилось в платформе: [retro-portal-games.md](retro-portal-games.md).

Версия 0.1 · 2026-09-30 · роли: PM, аналитик, геймдизайнер, маркетолог, разработчик, QA.
Игра: [QmaCyber/game2](https://github.com/QmaCyber/game2), ветка `claude/pensive-volta-f2zcxc`, коммит `ebb4fef`.

## Что произошло

Владелец попросил отдельного агента сделать игру для CrazyGames (13+). Агент изучил рынок и выбрал survivors-like
с мета-прогрессией: клетка против микробов, 7 видов оружия, 3 уровня, магазин улучшений за ДНК, rewarded-реклама.
Игру он написал **отдельным проектом, без платформы**. Из платформы он взял только адаптер портала, и то копией
(«Adapted from game_platform/packages/core/src/portal.ts»). REPORT.md по §7 AGENTS.md не написан.

Результат сильный: 5,7 тыс. строк, 45 проверок в браузере, бот для баланса, zip на 66 КБ. Первый мой прогон его
QA дал 15 из 17 и упал на проверке «реклама возвращает клетку». Повторный прогон — 45 из 45. Сбой был из-за
нагрузки: тест ждёт рекламу всего 400 мс.

## Разговор ролей

**PM:** Главный вопрос: почему агент не пошёл на платформу? Ведь для этого мы её и делали.

**Аналитик:** Его исследование отвечает прямо. На CrazyGames гиперказуал — худший жанр: 8,6 мин игры, D1 6%. Экшен
даёт лучший D1 (8,1%), incremental — самые длинные сессии (15 мин). У нас был только `tap-score`, то есть гиперказуал.
Агент выбрал жанр по рынку, а платформа этот жанр выразить не могла.

**Геймдизайнер:** И AGENTS.md не оставлял ему выхода: «не меняй packages/, пиши запрос блока». Запрос блока — это
«подожди следующую версию платформы». Агенту нужно было сделать игру сейчас, поэтому он ушёл.

**Разработчик:** Уход дорого ему обошёлся. Примерно 950 строк — портал, темп рекламы, сохранения, ввод, выключение звука,
e2e, упаковка — он написал сам, и проверял их только собственным QA. Всё это уже есть в платформе или должно быть в ней.

**QA:** Зато он сделал три вещи лучше нас. Первое: production-сборку он проверял с **подменённым SDK** (Playwright
route), а у нас в production-сборке SDK было «не проверено». Второе: rewarded-реклама — у нас её не было вообще.
Третье: проверка «gameplayStart/Stop всегда чередуются» через весь сценарий.

**Маркетолог:** Rewarded на CrazyGames — основной доход: revive, ×2 награда, reroll. Без неё платформа не годится
для веба. И мета-прогрессия: в кейсе Liquid Swarm снижение цены одного улучшения почти удвоило время игры.

**PM:** Значит, решение не «сделать survivors-like блоком». Жанров будет много, и каждый блоком не закроешь.
Решение — **второй путь внутри платформы**: игра со своим кодом, но на сервисах и правилах платформы. Тогда следующий
такой агент не уходит, а платформа проверяет то, в чём ошибаются чаще всего.

**Разработчик:** Это `kit: code`. `game.yaml` проверяется как у всех: канал, аудитория, лимиты рекламы. Игра — модуль
`start({ host, canvas, ui })`. `host` даёт портал с дедупликацией gameplay, `adBreak()` по лимитам канала, `rewarded()`
только после тапа игрока, звук, который сам замолкает во время рекламы, облачные сохранения по форме умолчаний,
seed и `MoveInput` (ввод из Petri Panic).

**QA:** Механику игры QA знать не может. Поэтому договоримся о трёх соглашениях: `data-gp="play"` на кнопке Play
(по нему production-проверка нажимает без хуков), `host.qa({ play, end, lose })` и `data-gp-rewarded` на
rewarded-кнопках. Остальное — общее для любой игры на портале.

**Геймдизайнер:** И правило «никакого continue за рекламу» в нашем руководстве надо разделить. Для детей — да, никакой
рекламы по выбору вообще. Для 13+ rewarded — это предложение, а не плата: кнопка говорит, что получишь, награда
приходит всегда, без рекламы можно пройти всё.

**Аналитик:** Данные рынка из его исследования — в руководство по геймдизайну, с оговоркой: они из веб-поиска,
сверять на docs.crazygames.com.

## Что не сделано (очередь)

- Блоки мета-прогрессии (валюта, магазин улучшений) для YAML-китов.
- Rewarded в `casual` (Continue или ×2 на экране результата).
- AdMob rewarded на Android.
- `kit: code` на Android (нужны иконки темы и правила Families).
- Перенос Petri Panic на `kit: code` — решает владелец; это репозиторий другого агента.

## Для агента Petri Panic (не правил: чужой репозиторий)

- Тест `revive ad brings the cell back` нестабилен: он ждёт рекламу 400 мс, а под нагрузкой это не успевает. Лучше
  ждать состояние (`waitForFunction(state === 'play')`), а не фиксированное время.
- Нет REPORT.md по §7 AGENTS.md. Главный пункт для него: «платформа не выражала жанр — поэтому писал сам».
